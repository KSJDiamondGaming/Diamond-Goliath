Goliath

Goliath is a full-featured Discord bot with a real-time web dashboard.
It combines moderation tools, automation, logging, and live configuration into one system.


Features
Auto Moderation
Spam protection
Link & invite filtering
Caps abuse detection
Bad word filtering
Custom punishments
Moderation System
Cases & warnings
Action logging
History tracking
Logging System
Separate log channels (admin, moderation, automod, etc.)
Event toggles for full control
Dashboard
Live configuration
Real-time updates via Socket.IO
Clean UI system
Real-Time Sync
Dashboard updates instantly when bot data changes


Requirements
Node.js v18+
npm
